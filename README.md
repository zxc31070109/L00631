# 📈 00631L & 台指期貨大盤 - 靜態趨勢分析儀表板 (L00631)

本專案是一個專門解析 Google Sheet 的靜態網頁應用程式，具備毫秒級極速 parsing、工作日去重處理、大字體高可讀性、以及專業趨勢圖表分析功能。

## 🌟 核心特色
- **⚡ 原生 GVIZ JSONP 極速 Parsing**：繞過傳統 CORS 阻擋與 Proxy 延遲，達到 100 毫秒級即時同步。
- **📅 工作日（Workday）去重與計算**：自動依據「日期」保留當日最後更新紀錄，精確計算單日漲跌金額與 %。
- **📊 雙分頁趨勢 K 線/折線圖**：
  - **00631L 分頁**：收盤價走勢、最高/最低標籤、MA5/MA20 移動平均線。
  - **台指期貨大盤分頁**：雙 Y 軸對比台指期貨點數與大盤加權指數。
  - **槓桿 vs 大盤分頁**：累積報酬率 (%) 歸一化同框比較。
- **🔍 搜尋與 CSV 下載**：支援關鍵字過濾日期與一鍵導出表格資料。
